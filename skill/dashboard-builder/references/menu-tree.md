## 실행학교 주차별 추가 (제안)

- 2주차: `kakao`, `meetingroom` (채널 연결 주) — 추가로 `sessions`, `calls`, `post`, `bizkakao` 가능
- 3주차: `news`, `landing` (마케팅 미디어 자동화 주) — 추가로 `youtube`, `dispatch`
- 4주차: `orders`, `sourcing` (쇼핑몰 주) — 추가로 `coupang`, `coupons`, `school`, `console`, `plaud`

사용자가 설정 화면에서 언제든 주차를 올리거나 메뉴를 더할 수 있다. 주차는 "잠금"이지 "삭제"가 아니다.

## 담당 추천 규칙

- 총괄 비서 → `tasks`, `agents`, `notes` (지시가 모이는 곳)
- 코딩 담당 → `settings` (환경·스크립트)
- 글감/콘텐츠 담당 → `ideas`, `news`, `landing`
- 응대 담당 → `email`, `kakao`, `bizkakao`, `calls`, `contacts`
- 운영/쇼핑몰 담당 → `orders`, `sourcing`, `coupang`, `coupons`
- 맞는 직원이 없으면 "담당 없음". 대시보드 팀관리 화면이 담당 없는 메뉴를 알려준다.
